# ⚡ Quick Reference - New Features

## 🎮 Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl+S` | Save project |
| `Ctrl+Shift+P` | Format code |
| `Ctrl+F` | Find in file |
| `Ctrl+H` | Find & replace |
| `Ctrl+Shift+K` | Show shortcuts |
| `Ctrl+Shift+L` | Toggle console |
| `Ctrl+/` | Toggle comment |
| `Ctrl+D` | Select next occurrence |

## 🔧 Feature Locations

### Editor Toolbar
- 🔍 **Search** - Find & replace
- 📄 **Snippets** - Insert code snippets  
- ✨ **Format** - Format current file

### Navbar (Top)
- ⌨️ **Keyboard** - Show shortcuts
- 🕐 **History** - Version snapshots
- 🔗 **Share** - Share project
- 📦 **Export** - Download/Export options
- 💾 **Save** - Save project

### Sidebar (Left)
- ➕ **Plus** - Create new file
- ⬆️ **Upload** - Upload files
- 📁 **Upload ZIP** - Import ZIP
- On hover: **Download** - Download file

### Console (Bottom)
- Toggle with `Ctrl+Shift+L`
- Filter: All / Errors / Warnings
- 🗑️ Clear console

## 📦 Quick Actions

### Upload Files
1. Click upload icon (sidebar)
2. Select files
3. Done!

### Create Snapshot
1. Click "History" (navbar)
2. Click "Create Snapshot"
3. Snapshot saved!

### Insert Snippet
1. Click snippet icon (editor)
2. Browse or search
3. Click "Insert"

### Format Code
1. Press `Ctrl+Shift+P`
2. Or click "Format" button
3. Code formatted!

### Download Project
1. Click "Export" (navbar)
2. Choose "Download ZIP"
3. Project downloaded!

## 💡 Power User Tips

1. **Learn shortcuts** - Way faster than clicking
2. **Create snapshots** - Before big changes
3. **Use snippets** - For common patterns
4. **Check console** - Catch errors early
5. **Format often** - Keep code clean

## 🐛 Debug Workflow

1. Press `Ctrl+Shift+L` - Open console
2. Check for errors (red)
3. Click error to see details
4. Fix code
5. Press `Ctrl+S` - Save

## 🔄 Version Control Workflow

1. Make changes
2. Click "History" → "Create Snapshot"
3. Continue coding
4. Need to rollback? Load previous snapshot

## 📤 Export Workflow

### Quick Export
1. Click "Export"
2. Choose platform
3. Project opens externally

### Full Download
1. Click "Export"  
2. "Download ZIP"
3. Extract and use anywhere
